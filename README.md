Moonward — a tiny fox with a flowing red scarf rides a gigantic luminous koi out of a dark teal ocean toward a golden moon. Crisp vector-style shapes, suspended droplets, and an indigo star field capture the leap.

## Run it

```sh
python3 main.py
```

The deterministic 1024×1024 RGB PNG is written to `/output/entry.png` (override with `MAKEFUN_OUTPUT_DIR`). Python 3.13, standard library only — all drawing primitives, supersampling, and PNG encoding are implemented in `main.py`.
